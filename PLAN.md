# План: Tauri-приложение «Color Studio» — подбор цветов и палитр

## Цель
Нативное приложение на Tauri v2 (React + TypeScript + Vite) для подбора цветов:
цветовое колесо с перетаскиванием, слайдеры HSL, генерация гармоний
(комплиментарные, монохром, и т.д.), кнопка «Случайная палитра»,
копирование цветов в буфер.

- Tauri v2, Rust (тонкая backend-обвязка)
- React 19 + TypeScript + Vite

  `navigator.clipboard` и `execCommand`
- Чистый CSS (без тяжёлых UI-фреймворков)
