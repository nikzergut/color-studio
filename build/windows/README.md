# Windows-сборка Color Studio 0.1.0

Собрано 2026-11-25, целевая платформа — Windows x64.

## Файлы

- `nsis/Color Studio_0.1.0_x64-setup.exe` — инсталлятор NSIS (рекомендуется для установки).
- `color-studio.exe` — исполняемый файл без инсталлятора (можно запускать напрямую,
  но без интеграции в меню «Пуск» и удаления).

Инсталлятор собран командой:

```bash
npm run build:win
```

Команда сама собирает frontend и Rust-часть в release-режиме, создаёт NSIS-пакет
и копирует артефакты в эту папку.

Сборка включает фирменные иконки, строгий CSP и нативный доступ к буферу обмена
через `@tauri-apps/plugin-clipboard-manager`.

Требование к ОС: Windows 10/11 с установленным WebView2 Runtime (обычно уже есть
в системе).
